# Knowledge and skills

Lorecrew keeps durable knowledge in a Git-backed Markdown vault. Definitions, memories, lessons, decisions, skills and readable history stay inspectable outside the service, including in an editor such as Obsidian.

## Find and reuse experience

Use **Knowledge** to search concepts and inspect their source references. Agents can search and load relevant knowledge during work. Search is keyword-based; mandatory embeddings or a separate vector service are not required.

Evidence states matter: a tentative lesson is not a validated procedure. Authorship, a model's confidence or a copied verification label does not establish a successful test. Inspect linked source work and recorded evidence, including contested claims.

## Background learning

Configure a learning curator deliberately. Captured work can produce source-linked lessons and candidate refinements. Background learning yields at defined boundaries when foreground work needs attention. This preview does not enforce monetary/token budgets, so choose providers and enabled routines intentionally.

## Skills

Skills are reusable instructions with descriptions, scopes and supporting resources. Agent, group and global scopes organize discovery; they are not privacy boundaries. New work can discover current active skills. Existing work retains loaded skill/resource revisions through edits, deletion and restart until an explicit supported reload.

Create a candidate, review its audience and instructions, and deliberately trial it when appropriate. Automatic improvement requires reproducible named checks and no known regression; manual unvalidated activation is a distinct choice. Candidate and historical versions remain inspectable when activation changes.

## Import a public text bundle

The skill importer accepts supported public GitHub-backed skills.sh and GitHub links. Resolve an explicit source/ref, inspect its frozen commit, inventory, resources, license attribution and adaptation before saving an inactive candidate. Supporting scripts are retained as inert text; importing does not install dependencies or execute them.

Binary, linked, unsafe or oversized bundles block complete import with diagnostics. Private/authenticated sources, arbitrary hosts, directory-wide search, packs, automatic updates and complete multi-file export are not included. An explicitly adapted single text import must not be represented as a complete bundle.

## Edit the vault safely

External editors do not honor Lorecrew's private locks. Detected conflicts preserve observed revisions and defer unsafe replacement, but arbitrary concurrent editor saves cannot be guaranteed loss-free. Pause synchronization or coordinate an editing window for sensitive changes. Stop all writers for backup/recovery.
