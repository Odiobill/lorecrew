Developer preview; source installation is available. Registry publication and a stable release are separate steps.

- Vault-first setup, named agents and groups, model/provider setup and explicit thinking preferences.
- Durable conversations and project teamwork through Pi Durable, with supervised host tools and explicit user questions.
- Projects catalog/details with create, add-existing and recorded-clone flows.

- Independent instances, explicit project ownership, stopped handoff and quarantined backup recovery.
- Public user documentation and a GitHub Pages product website.
